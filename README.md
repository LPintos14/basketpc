# BasketPC

Espacio de trabajo para entender, ordenar y documentar **BasketPC**, un simulador/mánager de baloncesto en línea.

## Objetivo

BasketPC tiene una dinámica muy particular y mucha información repartida en el foro. Este repositorio sirve para:

- Reunir la información del juego en un solo lugar.
- Resumirla y organizarla por temas para que sea fácil de digerir.
- Ir sumando notas, dudas y conclusiones propias.

## Temas

- **General**: reglas y funcionamiento básico.
- **Equipo**: plantilla, jugadores, entrenamiento.
- **Partido**: simulación y tácticas.
- **Campeonato**: ligas, torneos y temporadas.
- **Mercado**: fichajes y traspasos.
- **Economía**: ingresos, gastos y finanzas del club.

## Fuente
